# OIBC 2026 – 집합자원 구성 최적화 + 하루전 발전량 예측

## 1. 개요
1. **발전량 예측**: LightGBM(L1 손실, SMP×k 가중)으로 발전소별 시간대 이용률(발전량/설비용량)을 예측한 뒤 설비용량을 곱해 kWh 로 환산
2. **집합자원 구성**: 학습 구간의 주(week) 블록 교차검증 OOF 오차를 이용해, 두 집합의 `Σ SMP·k·|집합 오차 합|` 을 최소화하도록 시뮬레이티드 어닐링으로 253개 발전소를 G1/G2 에 배분 (집합별 설비용량 20,000 kW 이상 제약 유지)

## 3. 예측 편향 보정 (`bias_mode`)
* 시간대별 예측 치우침(낮 시간대 과대, 아침·저녁 과소)을 곱셈 계수로 보정 (`CFG["bias_mode"]`, 기본 `"peak"`: 피크(`k=3`)/비피크 2개 계수)
* 계수는 **학습 구간의 교차검증(OOF) 예측과 실적**만으로 산출 (페널티 `Σ SMP·k·|집합 합계 오차|` 를 최소화하는 가중중앙값 사용, 평가 구간 정보 미사용)
* `"none"` 설정 시 보정 없는 결과와 동일

## 4. 누수 방지 설계

| 점검 항목 | 처리 방식 |
|---|---|
| **대상일 실제 SMP 사용** | 예측 피처에 SMP 없음. `SMP×k` 는 **학습 행의 `sample_weight`** 와 구성 최적화(학습 구간 오차 가중)에만 사용. 평가/제출 프레임에는 SMP 미부착 (`make_frame(..., with_w=False)`) |
| **평가 구간 통계 사용** | 결측 대체 중앙값은 **학습 구간**에서만 계산해 평가·제출 프레임에 전달 (`make_frame(..., med=...)`). 평가 구간 전체 평균/표준화·그룹 분할 없이 모든 행을 독립 예측 |
| **미래 값 사용** | 예보 결측 보간은 같은 지점의 **과거 값 `ffill`(최대 6행)** 만 사용 |
| **직전 실적 입력** | 실적 시차(lag) 피처 없음. 실적 기반 피처는 학습 구간의 발전소별 평균 이용률(`site_cf`) 하나뿐 |

## 7. 재현성 및 최종 제출 재현 절차
### 7-1. 재현성 설정
* **시드 고정**: 최종 예측 `(0, 1, 2)` 평균, 구성 최적화 시드 동일. LightGBM `deterministic=True`, `force_row_wise=True`, `n_jobs` 고정(`CFG["n_jobs"]`)
* **제출 학습 구간**: `CFG["submit_train_from"]` = `2023-06-01` 이후
* **출력 파일**: `composition.csv`(`site_id, group`), `forecast.csv`(`group, ts, forecast_kwh`; 2집합 × 8,760시간 = 17,520행)
* **예측 시점 처리**: 대상일 전날 17:00 까지 알 수 있는 정보만 사용 (예보는 전날 10시·17시 발행분, SMP 는 학습 구간 표본 가중치로만 사용, `site_cf` 는 `causal` 모드에서 각 대상일의 예측시점(`ts` 17:00)까지의 실적만 사용)

### 7-2. 최종 제출본(`v06`) 재현 순서
1. 위 환경을 설치하고, 대회 데이터를 `run.py` 와 같은 폴더에 위치시킨다 (`sites.csv`, `smp.csv`, `train/`, `test/`).
2. `run.py` 설정을 아래와 같이 맞춘다.
   * `SITE_CF_MODE = "causal"`
   * `ENSEMBLE = None`
   * `BIAS_MODE = "peak"`, `SUBMIT_SEEDS = (0, 1, 2)`, `SA_SEEDS = tuple(range(10, 22))`, `N_KEEP = 8`, `RUN_VARIANTS = True` (그 외 스위치 `False`)
3. `python run.py` 실행 → `out_var/v00 … v08` 생성. **최종 제출본 = `out_var/v06`** (`Claude AI 사용`).
4. 동일 설정으로 재실행했을 때 `out_var/v06` 폴더의 `composition.csv`·`forecast.csv` 가 제출본과 일치하는지 확인한다 (`check_variants.py` 의 재현 점검 사용).

##회고 (Retrospective)성공 요인: 도메인 특성을 반영한 손실 함수 설계($\text{L1} + \text{SMP} \times k$ 가중)와 구성 최적화, 편향 보정을 통해 안정적인 우상향을 이끌어냄. 특히 구성 최적화는 로컬 검증과 실제 제출 간의 괴리가 거의 없이 100% 이상의 효율을 보여줌.
##아쉬운 점 및 향후 과제: 구성 최적화의 이론적 한계치에 근접한 이후, 본질적인 '전체 발전량 예측 정확도'를 높이는 피처 엔지니어링이나 외부 기상 데이터 활용에서 돌파구를 찾지 못함 추후 유사한 시계열 예측 및 최적화 문제에서는 최적화 단계 이전에 원시 예측 모델의 표현력을 높이는 데 더 많은 리소스를 집중할 계획.
